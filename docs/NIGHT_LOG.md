  `SCEN=s2|heretic|hurt|strong|mix`로 시작 상황을 바꾸고, `COVER=1`이면 커버리지를 찍는다.
- `fuzz-ui.tsx` — 퍼징 중인 상태로 모든 화면·캐릭터 시트·도감·묘지를 서버 렌더링(예외, 화면의 undefined/NaN, 미궁 도크에 버튼 없음).
- `fuzz-determinism.ts` — 같은 시드를 두 번 돌려 결과 비교(모듈 전역 상태 누수), `act`가 이전 상태를 건드리지 않는지.

돌린 양: 게임 로직 약 2만 판·1000만 행동, UI 렌더 약 12만 번, 결정성 300판. 예외·멈춤·봇 멈춤 0.

고친 버그(각각 회귀 테스트 추가, src/game/game.test.ts "퍼징 회귀"):
1. **HP가 최대치를 넘는 상태** — 최대 HP를 올려 주던 장비를 다른 것으로 바꿀 때, 역병의 신 ★3(병든 동안 최대 HP +4)이
   병이 낫거나 신앙이 떨어지거나 신앙을 포기해 꺼질 때 현재 HP가 그대로 남았다. 행동이 끝날 때마다 HP를 최대치로 맞춘다(engine.ts).
2. **2섹터 차원문으로 돌아와도 "1섹터의 차원문에 도달" / "1섹터 클리어!"** — 정산에 섹터를 기록해 맞게 표시하고,
   이미 넘은 섹터를 다시 넘었을 때는 "등급이 올랐다"를 쓰지 않는다.
3. 자잘한 것: 타이틀 "1섹터(3층)까지" → "2섹터까지", 여관 주석의 낡은 가격.

- 현상수배 상태에서 시작한 퍼징 판은 거의 다 죽는다(무작위 행동이 섞인 판 기준). 규칙대로의 결과로 보여 손대지 않음.
