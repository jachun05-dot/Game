# 다국어(i18n)

2026-10-20 사용자 요청: 영어·일본어·간체 중국어. 단계별로 번역한다.

| 단계 | 범위 | 상태 |
|---|---|---|
| 1 | 언어 선택, 화면(UI): 메뉴·버튼·화면 글·안내(`src/ui`) | 완료(2026-10-20, 582문장) |
| 2 | 게임 데이터: 아이템·장비·몬스터·기술·신·편린 이름과 설명(`src/game` 데이터) | 대기 |
| 3 | 로그·스토리: 전투·미궁·마을 로그, 엔딩, 기록물 | 대기 |

## 방식

- **한국어 원문이 곧 키**다: `t("묘지")`. 번역이 없으면 한국어 원문이 그대로 나온다(빠져도 깨지지 않는다).
- 번역은 `src/i18n/locales/<en|ja|zh>/<영역>.json` — `{ "한국어 원문": "번역" }`. 고른 언어 파일만 내려받는다.
- 끼워 넣기: `t("잠든 모험가 {n}명", { n })`. 번역문도 같은 `{n}`을 써야 한다(순서는 바꿔도 됨).
- 한국어 조사: `t("{faith|을} 부정한다", { faith })` — 한국어에서만 조사가 붙는다. 번역문에서는 `{faith}`.
- `t()` 안에는 **큰따옴표 한 줄짜리 정적 문자열**만 쓴다(점검 스크립트가 찾을 수 있게). 템플릿 문자열 `${}`을 t() 안에 넣지 않는다.
- 화면 밖(모듈 최상단 배열·객체)에서 정해 두는 글: `tk("구석구석 탐험")`으로 표시만 하고, 그릴 때 `t(g.name)`.
- 한 문장 안에 `<b>` 같은 태그가 끼면 문장을 조각으로 나누지 말고 가능하면 태그 밖으로 빼거나, 조각마다 자연스러운 단위로 t()를 쓴다.
- 게임 데이터 값(신 이름, 아이템 이름 등 `src/game`에서 오는 글)은 2단계 몫이다. 화면에서 그대로 보여 주는 곳은 `t(값)`으로 감싸 두면 2단계에서 사전만 채우면 된다.
- 일부러 한국어를 두는 줄은 끝에 `// i18n-ok`(JSX는 `{/* i18n-ok */}`).
- 점검: `npm run i18n:check` — 빠진 번역, `{이름}` 불일치, 아직 감싸지 않은 한국어(src/ui)를 알려 준다.
- 언어는 기기에 저장(`ddd-lang`), 처음엔 기기 언어(한·일·중 외에는 영어). 타이틀 아래와 ⚙ 설정에서 바꾼다.
- 일·중은 Noto Sans/Serif JP·SC 글꼴을 따로 받는다(`theme.css`의 `:lang()`).

## 번역 문체

- 톤: 다크 판타지. 짧고 건조하게. 설명문은 정보가 우선.
- 영어: 버튼·제목은 Title Case 대신 Sentence case. 수치 설명은 간결하게("HP +40").
- 일본어: 지문·서술은 だ・である調, 버튼·안내는 짧은 체언/です・ます 없이 간결하게. 고유 용어는 아래 표.
- 중국어(간체): 서면어, 간결하게. 전각 문장부호(，。：「」).
- 수치·기호(G, HP, AC, Lv, ★, ×, ·)는 그대로 둔다.

## 2·3단계에서 챙길 것

- `src/ui/art.ts`의 `WEEK_SCENE`은 주간 결과 제목(한국어)으로 그림을 찾는다 — 3단계에서 제목을 번역하면 키를 id로 바꿔야 한다.
- `components.tsx`의 훈련 이름에서 " 수련/훈련"을 정규식으로 떼는 두 줄(`i18n-ok`) — 2단계에서 훈련 이름을 번역할 때 바꾼다.
- `TownScreen.tsx`의 `ActivityButton` 아이콘은 한국어 제목을 정규식으로 본다(번역 전 원문을 넘기므로 지금은 문제없다).
- 보스 증표 이름(위 표)은 2단계 몬스터 이름(균모·화로 어미·아귀)과 맞춘다.
