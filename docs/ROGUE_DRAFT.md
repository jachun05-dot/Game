# 로그(민첩 직업) 초안 (2026-10-19, 결정 전)

사용자: "민첩직업을 추가하자. 로그야". 구현은 결정 뒤에.

## 정체성
- 영지 뒷골목에서 자란 소년. **빠르고 약하다** — HP가 가장 낮은 축, 대신 첫 일격·치명타·독·도주·약탈로 산다.
- 전사(힘)·마법사(지능)처럼 **모든 훈련이 민첩을 올린다**. 단검·숏소드는 민첩으로 다룬다. 민첩 35면 행동 2회(기존 규칙)에 가장 빨리 닿는 직업.
- 모험가의 민첩형 갈래는 그대로 둔다(맛보기). 로그는 같은 방향을 **깊고 좁게** — 기술은 따로 만든다(일부 공용 기술은 전사처럼 공유 가능).
- 약점: 보스(HP 큰 단일 적)와 오래 끄는 싸움 → 독술 갈래가 메운다.

## 훈련 세 갈래
- **암습** (민첩·감각): 첫 일격과 치명타. 잡몹을 빨리 지운다
- **독술** (민첩·지능): 독·마비·약화. 보스와 긴 싸움
- **약탈** (민첩·행운): 마석·회피·함정·도주. 돈 — 세금이 무서운 이 게임에서 경제를 맡는다
