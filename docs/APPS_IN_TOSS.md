# 앱인토스 출시 준비 (2026-10-28 조사)

출처: 앱인토스 개발자센터(developers-apps-in-toss.toss.im — `llms.txt`, `checklist/app-game.md`, `intro/guide.md`, `ai-vibe-coding/tutorials/webview.md`), 앱인토스 블로그. 정책은 수시로 바뀌므로 신청 직전에 다시 확인한다.

## 1. 사람이 해야 하는 일(코드 밖)

- 앱인토스 콘솔 워크스페이스·앱 등록(`appName` 확정 — 설정 파일과 같아야 업로드된다)
- 사업자등록, 게임제작업 등록(블로그 안내: 게임은 개인도 필요)
- **게임물관리위원회(GRAC) 등급분류 필수** — 앱스토어·구글플레이 IARC 등급은 국내에서 효력 없음. 약 10~15일
- `.ait` 업로드 → 테스트 앱스킴으로 실기기 확인 → 검수 요청(영업일 2~3일, 운영·기능·디자인·보안) → 출시하기

## 2. 콘텐츠 정책 — 이 게임의 가장 큰 위험

- 「만들 수 없는 콘텐츠」 불법·범죄 조장 항목: "미성년자 등장 콘텐츠는 즉시 삭제되고 신고돼요"
- 폭력성: 타격·고통 묘사·피 = 2단계(주의), 유혈·잔혹·학대·고문 = 3단계(출시 불가). 주의 단계여도 내부 심의로 출시 제한 가능
- 이 게임(웹판): 주인공 16~17세, 세금 미납 처형, 18세 처형, 머리·몸통 결손 즉사, "아동 사망·처형" 경고 문구
- → 결정(2026-10-28): 토스판은 규칙·수치는 그대로, 글만 바꾼다. 덮어쓰기 사전 `src/i18n/variants/toss/{ko,en,ja,zh}/toss.json`(언어마다 53개), 새 키 번역은 `src/i18n/locales/{en,ja,zh}/toss.json`
  - 나이 → 수습 연차: 주인공은 "수습 모험가". 1~12월 수습 1년차, 13~24월 수습 2년차, 25월 = "수습 기한이 끝나는 날". 미궁은 갓 등록한 수습 모험가만, 수습 두 해 동안만 받아들인다(셉터의 마법·영주 설정은 그대로). 표어 "수습 모험가, 미궁으로". 후보 이름 "○○ 소년" → "○○ 신참", 기본 이름 "이름 없는 신참"
  - 처형 → 추방·투옥: 세금 미납은 섬에서 추방(게임 오버는 그대로), 수습 기한 날 추적자에게 지면 감옥행. 탐욕의 신 "빚 문서"·"피의 값"은 추방 면제. 타이틀 경고는 "죽음 등 무거운 장면이 나옵니다"
  - 잔혹 묘사 순화: 사인 "머리를 잃었다/몸통을 꿰뚫려/피를 너무 많이 흘려" → "치명상을 입고/깊은 상처를 입고/상처가 깊어 쓰러졌다", 까마귀 설명의 시체·6섹터 화형대 → 중립 묘사. 출혈·결손 같은 규칙 용어는 그대로
  - 이름 바꿈: 몬스터 "처형인의 갑주" → "심판관의 갑주"(편린 "심판관의 갑주의 편린", en Arbiter's Armor), 로그·편린 기술 "처형" → "결정타"(en Decisive Blow, ja 決定打, zh 决胜一击)
  - 점검: `bun scripts/toss-scan.ts all 8`(0개여야 한다), `node scripts/i18n-check.mjs --strict src`

## 4. 연동 절차(웹 프로젝트)

```sh
npm install @apps-in-toss/web-framework   # 2026-10 기준 3.9.0
npx ait init                              # apps-in-toss.config.ts 생성
```

```ts
import { defineConfig } from "@apps-in-toss/web-framework/config";
export default defineConfig({
  appName: "<콘솔에 등록한 이름>",
  brand: { primaryColor: "#…" },
  webView: {},
  permissions: [],
  webBundleDir: "dist",
});
```

- 비게임 미니앱은 TDS 필수, 게임은 체크리스트에 TDS 항목 없음
- 배포 API 키는 콘솔에서 발급(사용자 보관, 저장소에 넣지 않는다)

## 5. 빌드 상태(2026-10-28)

- `toss/`에서 `npm run build` → `toss/ddd-labyrinth.ait` 생성 확인(약 2.7MB)
- 토스판 글 점검 `bun scripts/toss-scan.ts all` → 네 언어 0건
- 남은 것: 콘솔에서 appName 확정(`toss/apps-in-toss.config.ts`), 테스트 앱스킴으로 실기기 확인, 사업자·게임제작업·등급분류
